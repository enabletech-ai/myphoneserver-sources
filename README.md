# MyPhoneServer component sources

This repository provides the open-source component sources distributed with MyPhoneServer. Each upstream component retains its own license. Proprietary application source is not included.

## Source releases

- [0.2.4 component sources](https://github.com/enabletech-ai/myphoneserver-sources/releases/tag/v0.2.4-components): Ubuntu source package versions, Node.js, Python components, PRoot, talloc, android-shmem, and pinned Termux build recipes.
- The release includes SHA-256 checksums and the native rebuild record. PRoot, its loader, and talloc rebuilt byte-identically to the shipped binaries. android-shmem differs only in build-identification sections.
- Source questions: developer@enabletech.me

This repository is a source distribution. It does not distribute the MyPhoneServer Android app or claim Google Play approval.
